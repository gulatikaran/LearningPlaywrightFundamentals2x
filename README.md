# Learning Playwright Fundamentals 🚀

This repository contains my practice code, automation scripts, and foundational exercises for mastering web automation and testing using **Playwright with TypeScript**.

## 🛠️ Tech Stack & Tools
* **Testing Framework:** Playwright (`@playwright/test`)
* **Language:** TypeScript / JavaScript
* **Test Runner:** Playwright Test Runner

## 📂 Repository Structure
* `tests/`: Contains spec files and automated test scenarios.
* `playwright.config.ts`: Configuration file for Playwright test settings, browsers, and viewports.
